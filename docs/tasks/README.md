# 작업 연구와 계획

> 담는 것: 구현 검토에 필요한 작업 문서의 진입 경로. 담지 않는 것: 작업 소유권(→ [과업 보드](../../workboard/README.md)). 읽는 시점: 연구 결과와 구현 계획을 검토하거나 이어받을 때.

현재 분류와 사용자 결정의 실행 계약은 [컴포넌트 정본](../../dev/COMPONENTS.md)을 따른다.
새 프로젝트 시작은 [하네스 조립 절차](../../dev/workflows/harness-assembly.md)를 따른다.
완료한 연구와 계획은 로컬 archive에 함께 보관한다.
이전 컨텍스트 초안은 로컬 연구 근거로 보존하며 독립 실행 계획으로 사용하지 않는다.
