# docs/BACKLOG.md — 잔여 백로그

> 담는 것: 아직 착수하지 않은 일과 그 판단 근거. 담지 않는 것: 지금 누가 무엇을 잡고 있나와 착수~완료 절차(→ `workboard/README.md`)·세션 행동 규칙(→ `CLAUDE.md`). 읽는 시점: 다음 과업을 고를 때.

> **진행 중 과업은 여기 없다.** `workboard/` 가 그 자리다 — 파일 하나가 과업 하나이고
> git 에 추적되지 않는다. 이 파일은 **남은 일**만 쥔다.

> **열린 것만 남긴다.** 완료·기각 행은 지운다 — 경위는 git 이력과 `docs/tasks/archive/`에 있고, 여기 쌓이면 "지금 뭐가 남았나"를 못 읽는다.
> ⚠️ **착수 전에 서술을 실물로 대조한다.** 원류 정리에서 8건 중 5건이 "착수해보니 이미 해결돼 있었다"였고 3건은 전제가 통째로 낡아 있었다. 백로그는 **관측이 아니라 기억**이다.

> 🚫 **여기는 하네스 자신의 백로그다.** 이 레포엔 앱 코드가 없다(`ARCH = "headless"`, 레이어 전부 `None`). 화면·테이블·라우트가 생기는 것을 전제한 항목은 여기가 아니라 **하네스를 설치한 소비 프로젝트**의 일이다. 그런 항목이 섞이면 영원히 착수되지 않은 채 목록만 불린다 — 실제로 6주간 2건이 그랬다.

| 우선순위 | 항목 | 설명 |
|----------|------|------|
| 🟡 중간 | 하네스 지도 대조 양방향 | `check_harness_map` 이 실물→지도 단방향이라 **지도에만 남은 유령 항목이 안 잡힌다**. 실물이 사라져도 지도는 조용하다. 역방향 순회를 더한다 (같은 항목에 묶여 있던 PreToolUse(Bash) 훅은 이미 실물로 존재한다) |
| 🔵 낮음 | pytest 선별 실행 게이트 | `tests/` 전제는 이미 충족됐다. 막는 것은 **전량 4분**이라는 실측이다 — 매 턴 도는 Stop 훅의 현행 최장 timeout 이 120초다. 변경 파일에 걸리는 테스트만 고르는 선별 실행이 선결 과제이고, 그 전까지는 수동이 맞다. 프론트 타입체크는 headless 라 해당 없음 |
| 🔵 낮음 | allowlist 외부 파일 통로 | 커널이 예외 목록을 **프로파일 모듈 인라인으로만** 읽는다. 목록이 수십 개를 넘는 프로젝트에선 프로파일이 목록 파일이 돼버린다. 별도 파일에서 읽어 합치는 통로를 둘지 정한다 — 실물 목록 이관은 그 프로젝트 소관이고 여기서 정할 것은 기전뿐이다 |
| 🔵 낮음 | impeccable 벤더 2.1MB | 102파일 2.14MB 로 `.claude/skills/` 전체 무게의 99%다. 화면 없는 프로젝트엔 순수 무게인데 **설치 스크립트에 스킬 선별 복사 로직 자체가 없다** — 제외 여부를 정하기 전에 제외할 수단부터 없는 상태다 |
| 🔵 낮음 | API 응답↔프론트 타입 필드 대조 | 라우트의 **존재** 여부는 이미 게이트다(소비 UI 없는 라우트). 남은 것은 응답 스키마의 **필드 대조**이고 이건 `qa` 에이전트 수동이다. 하류 프로젝트에 싣고 나가는 게이트라 이 레포에 화면이 없어도 유효하다 |
| 🔵 낮음 | security 검수 배선 | 인증·결제 도메인에 들어가는 프로젝트가 생기는 시점. 전용 에이전트 신설보다 **Claude Code 내장 `security-review` 스킬을 정책표에 연결**하는 쪽이 먼저다 — 지금 레포는 그 스킬을 어디서도 참조하지 않는다 |
| 🔵 낮음 | 중첩 def allowlist 기전 | 예외 통로가 scratch 경로 제외 하나뿐이라 파이썬에선 문자 그대로 전면 금지다. 데코레이터처럼 정당한 클로저가 필요해지는 시점에 구현한다. Go 는 언어팩이 "클로저가 관용구"라며 통째로 빼지만 파이썬엔 대응물이 없다 |
